# HC-SPEC Documentation

This directory contains the public specification of the Hub Cognitivo.

## Structure

```text
docs/
├── governance/
├── templates/
├── principles/
├── epistemology/
├── ontology/
├── architecture/
├── protocols/
├── rfc/
├── adr/
├── glossary/
└── examples/
```

The repository describes what an Hub Cognitivo is, why its architectural and epistemic principles exist, and which public contracts an implementation should respect. Proprietary implementation details belong in the private `HUB-COGNITIVO` repository.

## Bootstrap status

The documentation structure is currently being bootstrapped. Governance and templates are defined before canonical specification content is promoted.
